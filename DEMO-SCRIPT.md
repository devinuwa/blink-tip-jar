# 60-second demo script

**0:00–0:08**  
“This is Blink Tip Jar. A creator drops one link in an X post. Anyone can tip them in SOL or USDC without leaving the timeline.”

**0:08–0:18**  
Show the home page. Point at the creator wallet, the copyable Blink URL, and the Share on X button. “The page is only a window. The payment is a Solana Action.”

**0:18–0:32**  
Open the dial.to link. A wallet is already on devnet. Click **0.01 SOL**, or Custom SOL and type a short message. Approve. “The server returns an unsigned transaction: a transfer, and a memo that starts with `tipjar:`.”

**0:32–0:48**  
Cut back to the site. The new row slides in: shortened sender, amount, SOL badge, the message, how many seconds ago, and a Solscan devnet link. The totals tick up. “That feed is not a database. It reads the creator’s last transactions from devnet.”

**0:48–1:00**  
“Same buttons work for USDC. Fees are a fraction of a cent and the transfer settles in about a second, which is why a tip can live inside a social post. Mainnet is an environment-variable switch.”
